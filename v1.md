## Problem Statement

Build a UN-style multi-agent geopolitical simulation (WorldPolicy-Env) where 6 country/bloc agents make policy decisions (economics, geopolitics, climate) using MAPPO-trained PyTorch policy networks. Real-world events cascade through the system. When a natural disaster triggers, disasterman's Python modules are imported directly and activated as a sub-environment — macro agents observe relief outcomes and their rewards include disaster response quality. Visualized on a Deck.gl 3D globe with real-time country states and event arcs.

Context: This is a hackathon submission for Scaler x PyTorch x HuggingFace x Meta, Bengaluru, April 25-26 2026. Team of 3, building primarily with Claude Code. 2 prep days (April 22-23) before the hackathon.

## What Makes This Cool

The hierarchical nesting: classical PyTorch RL (MAPPO) at the macro level calling an LLM-based (Llama-3.3-70b via Groq) disaster response system at the sub-task level. This is the full sponsor stack — PyTorch training loop + HuggingFace deployment (combined backend on HF Spaces) + Meta Llama inference + Deck.gl 3D visualization.

No one else at this hackathon will have this. Everyone else either: (a) builds a pure LLM orchestration system with no real training, or (b) builds a classical MARL benchmark with no connection to deployed AI. This bridges both worlds.

The "whoa" moment: a disaster event triggers mid-simulation, the globe zooms in on the affected region, disasterman's ZoneScorerNet + LLM pipeline activates, the macro agents dispatch aid and the globe shows relief operations while the geopolitical simulation continues.

## Premises

1. disasterman (Rajy777/disasterman) is imported as Python modules: `environment.py`, `agents/`. Not called as an API service. WorldPolicyEnv + disasterman modules are bundled together in one FastAPI backend deployed on HuggingFace Spaces.
2. WorldPolicy-Env macro layer is built from scratch in ~4 days using Claude Code.
3. Macro country agents use MAPPO-trained PyTorch policy networks — NOT LLM agents. Real training loop with reward curves.
4. 3D Deck.gl globe in React, added to a fork of Rajy777/disasterman (frontend lives in the same repo).
5. Fixed at 6 country agents. Parameterization to 8 is deferred.

## Approaches Considered

### Approach A: Minimal Viable MARL
Flat PettingZoo env + IPPO + disasterman import + extended React map. Faster (8h CC), lower risk, less impressive visually. No 3D globe, no hierarchical RL.

### Approach B: Hierarchical MARL + 3D Globe (CHOSEN)
Two-level RL: MAPPO macro agents + DisasterEnvWrapper + Deck.gl 3D globe. Full sponsor stack integration. Technically novel. Timeline risk is real but Claude Code compresses it.

### Approach C: Event-Cascade Simulation
Scripted agents + cascade visualization, no training. Best visuals but judges see through it. No reward curves.

## Recommended Approach — Approach B

**Architecture:**

```
WorldPolicyEnv (PettingZoo ParallelEnv, N=6)
├── world_state: {
│     gdp[6], military[6], climate[6],
│     relations[6×6],        # bilateral relation scores, -1 to 1
│     active_crises[],       # list of CrisisEvent objects
│     disaster_severity: float,  # 0–1, triggers wrapper at > 0.7
│     step: int
│   }
├── country_agents[6]: MAPPO
│   ├── shared MLP backbone (input 36 → hidden [128, 128])
│   ├── 6 separate actor heads (one per agent, outputs logits over 8 actions)
│   ├── 1 centralized critic (takes full joint observation, all 6 agents' obs concatenated)
│   ├── obs per agent: 36-dim vector
│   │     own_state[3]        = gdp, military, climate (normalized 0–1)
│   │     neighbor_states[15] = gdp, military, climate for 5 other agents
│   │     own_relations[5]    = relation score to each other agent
│   │     global_indicators[5]= global_gdp_avg, global_temp, active_crisis_count,
│   │                           disaster_severity, step_fraction
│   │     crisis_flags[8]     = one-hot: war, pandemic, econ_crisis, disaster_active,
│   │                           sanction_target, trade_blocked, climate_emergency,
│   │                           in_alliance
│   └── actions: Discrete(8) — sanction, trade_deal, military_deploy,
│                               climate_pledge, aid_dispatch, propaganda,
│                               arms_race, neutral
├── event_engine: spawns crises from hardcoded scenario table (5 scenario types:
│     war, pandemic, econ_crash, natural_disaster, climate_emergency)
│     — parameterized events, NOT a live news feed
└── DisasterEnvWrapper (gym.Env)
    ├── wraps: disasterman/environment.py, disasterman/agents/
    ├── env var: GROQ_OFFLINE=1 causes wrapper to load from data/groq_cache.json
    │   instead of hitting Groq API (populate cache before hackathon)
    ├── DummyDisasterEnv (fallback if disasterman import fails at runtime)
    ├── reset() → initializes 10-zone disaster state
    └── step(total_resources: float) → {relief_score: float, zones_stabilized: int, casualties_saved: int}
        # total_resources = sum(0.2 for each agent that chose AID_DISPATCH this step)
```

**Observation vector schema (36-dim per agent):**

| Slice | Dims | Content |
|-------|------|---------|
| own_state | 3 | gdp, military, climate (normalized 0–1) |
| neighbor_states | 15 | gdp, military, climate for 5 other agents |
| own_relations | 5 | relations[i][j] for j≠i — row i of the 6×6 bilateral matrix, self excluded |
| global_indicators | 5 | global_gdp_avg, global_temp, active_crisis_count, disaster_severity, step_fraction |
| crisis_flags | 8 | one-hot: war, pandemic, econ_crisis, disaster_active, sanction_target, trade_blocked, climate_emergency, in_alliance |
| **Total** | **36** | |

Centralized critic input dim = 6 × 36 = 216 (all agents' obs concatenated).

**Derived state (computed each step, NOT stored in world_state):**
```python
# political_influence[i] = average positive relation strength (0–1)
political_influence[i] = sum(max(0, relations[i][j]) for j in range(6) if j != i) / 5

# cooperation_bonus[i] = 0.1 if agent i chose a cooperative action this step, else 0.0
cooperation_bonus[i] = 0.1 if actions[i] in {AID_DISPATCH, TRADE_DEAL, CLIMATE_PLEDGE} else 0.0
```

**Reward function (per country agent per step):**

When disaster sub-env is INACTIVE (disaster_severity ≤ 0.7):
```
r = 0.375 * Δgdp[i]
  + 0.250 * Δpolitical_influence[i]   # Δ from prev step
  + 0.250 * Δclimate[i]               # Δ from prev step
  + 0.125 * cooperation_bonus[i]
  # weights are 0.3, 0.2, 0.2, 0.1 rescaled to sum to 1.0 (÷ 0.8)
```

When disaster sub-env is ACTIVE (disaster_severity > 0.7):
```
r = 0.3 * Δgdp[i]
  + 0.2 * Δpolitical_influence[i]
  + 0.2 * Δclimate[i]
  + 0.2 * disaster_relief_quality     # = relief_score (0–1 scalar) from DisasterEnvWrapper.step()
  + 0.1 * cooperation_bonus[i]
```

**Action transition function (world_state mutations per step):**
```python
# All deltas are per-step magnitudes. gdp/military/climate clamped to [0, 1].
SANCTION(i, j):     relations[i][j] -= 0.10; gdp[j] -= 0.02
                    # j = argmin(relations[i]) — least friendly neighbor (natural sanction target)
TRADE_DEAL(i, j):   relations[i][j] += 0.15; gdp[i] += 0.01; gdp[j] += 0.01
                    # j = argmax(relations[i]) — best current ally
MILITARY_DEPLOY(i): military[i] += 0.10; gdp[i] -= 0.02
                    # if military[i] > 0.8 AND any neighbor military[j] > 0.7:
                    #   spawn WAR crisis (adds to active_crises)
CLIMATE_PLEDGE(i):  climate[i] += 0.05; gdp[i] -= 0.01
AID_DISPATCH(i):    military[i] -= 0.10 (resources allocated to relief)
                    # disaster_allocations[i] = 0.2 passed to DisasterEnvWrapper.step()
PROPAGANDA(i):      relations[i][argmin relations[i]] += 0.05
                    # boosts weakest relationship (improves derived political_influence)
                    # do NOT write to political_influence directly — it is derived
ARMS_RACE(i):       military[i] += 0.20; climate[i] -= 0.05; gdp[i] -= 0.03
NEUTRAL(i):         no state change
```

**Episode termination:**
- Fixed horizon: 200 parallel env steps (= 1 episode)
- Early termination: if any `gdp[i] < 0` (economic collapse) — episode ends immediately
- `truncated = step >= 200; terminated = any(gdp < 0)`

**DisasterEnvWrapper allocations mapping:**
- `allocations` is a `np.ndarray` of shape `(6,)`, values 0.0 or 0.2
- `allocations[i] = 0.2` if agent `i` chose `AID_DISPATCH` this step, else `0.0`
- `total_resources = float(allocations.sum())` — scalar passed to DisasterEnvWrapper
- DisasterEnvWrapper.step() signature: `step(total_resources: float) → {relief_score, zones_stabilized, casualties_saved}`
- Inside DisasterEnvWrapper: `total_resources` passed to disasterman's ZoneScorerNet as the
  `rescue_teams` budget; ZoneScorerNet handles the 10-zone distribution internally.
  Wrapper does NOT expose per-zone allocation to the macro layer.
- Architecture diagram on line 90 updated: `step(total_resources: float)` not `step(allocations)`

**Training:**
- MAPPO with shared backbone (input 36 → hidden [128, 128] → output per agent head), 6 actor heads, 1 centralized critic (input 216 → hidden [256, 256] → value scalar)
- Suggested hyperparameters: lr=3e-4, clip_eps=0.2, entropy_coeff=0.01, batch_size=256, rollout_len=1024
- "50k parallel env steps" = 50k calls to `WorldPolicyEnv.step()` (= 300k agent-steps)
- Training runs **locally on team laptop** with `GROQ_OFFLINE=1` set — disasterman LLM calls use cache, not Groq API, to avoid timeout during training
- Not on HF Spaces
- HF Spaces hosts **pre-trained frozen checkpoint + FastAPI backend**; React frontend on Vercel
- Vercel deployment is for permanent hosting; **demo day always uses localhost** (don't rely on Vercel at venue)
- Baselines: (1) random-policy, (2) rule-based heuristic (NEUTRAL until disaster, then AID_DISPATCH)
- Demo loads frozen checkpoint — not live training
- If 20k-step convergence check on April 23 shows no improvement over random: stop training, ship scripted fallback as primary demo. Remove "reward curve" success criterion in that case; all other criteria still apply.

**Scripted Fallback (MANDATORY — build April 23 morning, before globe work):**
A hardcoded event sequence that plays using scripted/hardcoded agent choices (NOT the trained policy):
1. Russia-Ukraine crisis spawns → energy prices spike globally (world_state mutation)
